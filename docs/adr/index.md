# Architecture Decision Records

ADRs are historical decision records. They explain the context and trade-offs behind past design choices, but they are not the current API reference.

For the full ADR directory index and naming notes, see [ADR README](./README.md).

If an ADR differs from current behavior or current reference docs, use `docs/reference/`, `src/`, and `tests/` as the source of truth.
