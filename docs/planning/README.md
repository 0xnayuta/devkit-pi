# Planning

`docs/planning/` collects future plans, proposals, and roadmap documents. **These documents do not represent current behavior.**

Current public contract and implemented API surface are documented in [`docs/reference/`](../reference/). Source code and tests in `src/` and `tests/` are the other canonical sources.

## Planning documents

- [add-convert_content-tool-plan.md](./add-convert_content-tool-plan.md): Proposed `convert_content` tool design. Not yet implemented.
- [personal-toolkit-feature-roadmap.md](./personal-toolkit-feature-roadmap.md): Roadmap for future toolkit features. Not yet implemented.

## Policy

- Proposed, roadmap, and plan documents describe possible future directions only.
- Do not treat planning documents as current public contract or implementation documentation.
- Tools, commands, fields, or error codes described here are not guaranteed to exist in the current release.
- If planning content conflicts with `docs/reference/`, `src/`, or `tests/`, treat the reference docs and source code as authoritative.
